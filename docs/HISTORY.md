# Champion Tennis 1.7.0 — Android

Приложение для групповых занятий Champion Club, Ижевск, ул. Орджоникидзе, 23Б. Android 8.0+. Нативные экраны, без WebView.

## Изменения 1.7.0

Пользователь больше не настраивает интеграцию: убраны экран ввода ключа, кнопки API-подключения и технические подсказки во входе, записи и разделе «Клуб». Отсутствующий ключ, ответы 401/403 и серверные ошибки показываются как обычная ошибка подключения с повторной попыткой. Ошибка доступа не выдаётся за пустую историю и не открывает экран SMS-кода без подтверждённого запроса. Сохранённые ранее настройки интеграции не используются. Контакты и клиентские сеансы сохранены.

Семнадцать инструментальных тестов прошли на отдельном эмуляторе и HTTP-сервере, включая проверку отсутствия технических настроек, пустого и неверного ключа, отсутствия лишних SMS/записей и сохранения обычных сценариев. Сборки sandbox/debug и Android Lint прошли.

Ключ задаётся разработчиком при сборке (инструкция ниже). В текущей обычной сборке ключ не задан: защищённые операции показывают ошибку подключения. Публичное расписание продолжает загружаться отдельно. Тестовая сборка использует прежний локальный контур.

## Настройка сборки для разработчика

Для клиентского входа, истории, бронирования и отмены нужен действующий Partner Token с соответствующим доступом. Пользователь приложения его не вводит. Перед сборкой задайте переменную окружения `YCLIENTS_PARTNER_TOKEN` либо добавьте `yclients.partnerToken=...` в корневой `local.properties`. Переменная окружения имеет приоритет. Не передавайте ключ в аргументах командной строки и не сохраняйте его в `gradle.properties` или исходниках.

`local.properties` исключён из исходного архива и правил версионирования. Gradle формирует `BuildConfig.PARTNER_TOKEN`; ключ включается в обычный APK, поэтому извлекаем из него. Не выводится в логи или UI. В sandbox используется только локальный тестовый ключ. Старые пользовательские настройки интеграции игнорируются.

Вход для игрока: «Войти → номер телефона → Получить код → код из SMS». История и статистика загружаются после входа. Если ключ отсутствует или сервер запрещает доступ, приложение показывает обычную ошибку подключения. Публичный ключ виджета применяется только для чтения расписания и не подменяет ключ приложения.

**Проверка защищённых операций с реальным ключом пока не выполнена: ключ не предоставлен.** Проверки выполнены на отдельном локальном сервере. Ошибки загрузки не подменяются пустыми данными.

Клуб сейчас не требует отдельного SMS-подтверждения создания записи. Если он включит это требование или обязательное отчество, текущая форма заблокирует отправку до реализации этих режимов. Вход в аккаунт и отдельное подтверждение новой записи — разные операции API.

## Нативная запись и хранение

Живое расписание, календарь, уровни, корты, цены, свободные места. Перед бронированием повторно проверяются условия и доступность. Нужны имя, телефон и отдельное согласие на передачу данных. Рекламная рассылка не включается. Контакты можно сохранять и удалять; комментарий и согласие не переиспользуются.

Статус «Вы записаны» появляется только после ответа YCLIENTS с номером записи. При потере ответа результат неизвестен: повторная отправка блокируется, чтобы избежать дубля. Снять блокировку можно в «Клуб → История отправок» после проверки результата у клуба.

Контакты, сеанс и история отправок шифруются AES-256-GCM, ключ в Android Keystore. Автоматическое резервное копирование отключено. Список серверных записей хранится только в памяти и не используется между аккаунтами. Приложение запрашивает только INTERNET; рекламных/аналитических SDK нет. Номер и код передаются YCLIENTS при входе; контакты передаются YCLIENTS и клубу при бронировании.

## API и сборка

Официальная документация: https://developers.yclients.com/.

- `POST /api/v1/book_code/1538880` — запрос SMS-кода.
- `POST /api/v1/user/auth` — вход по номеру/коду, получение пользовательского токена.
- `GET /api/v1/user/records` — записи аккаунта; Bearer Partner Token и User Token из входа клиента.
- `POST /api/v1/activity/1538880/{activity_id}/book` — групповая запись.

POST-запросы автоматически не повторяются. Партнёрский ключ включается в APK при сборке и не выводится в логи; клиентский токен хранится зашифрованным. Чтение расписания через `YclientsApi` зависит от текущего публичного виджета и может потребовать обновления.

Java 17, Android SDK 36, Gradle 8.13, Android Gradle Plugin 8.13.2. Открыть каталог в Android Studio; сборка `./gradlew :app:assembleDebug`, проверка `./gradlew :app:lintDebug`. APK подписан debug-ключом. Для RuStore потребуются постоянная релизная подпись, данные издателя и опубликованная политика конфиденциальности.

## Локальный контур на компьютере

Добавлена отдельная сборка `sandbox` с ID `club.champion.tennis.sandbox`, названием «Champion Тест» и пометками тестового режима. Обычное приложение и его данные сохраняются отдельно. Сборка обращается только к `http://127.0.0.1:18765` через USB-проброс `adb reverse`; при недоступном сервере перехода к YCLIENTS нет. HTTP разрешён только loopback-домену в манифесте тестовой сборки. Обычные `debug`/`release` используют прежний HTTPS.

Сервер, панель управления, инструкция и запуск находятся в соседнем каталоге `champion-local-server`. Номер `70000000000` (второй аккаунт `70000000001`), код `1234`, реальный Partner Token не нужен. Сервер принимает только эти тестовые номера. Расписание генерируется относительно текущей даты в Ижевске, данные и сеансы сохраняются в SQLite на компьютере. Это собственный имитатор нужных методов, а не официальный тестовый стенд YCLIENTS.

Сборка приложения: `./gradlew :app:assembleSandbox :app:lintSandbox`.

Сборка тестов локального HTTP: `./gradlew -PtestBuildType=sandbox :app:assembleSandboxAndroidTest`. После установки APK и тестового APK в эмулятор и `adb -s emulator-5554 reverse tcp:18765 tcp:18765` выполнить `adb -s emulator-5554 shell am instrument -w -e class club.champion.tennis.LocalServerTest club.champion.tennis.sandbox.test/android.test.InstrumentationTestRunner`. Локальные тесты запускать только против sandbox; прежний AppTest предназначен для обычной сборки.

24 октября 2026: проверены локальные HTTP-сценарии сервера и два Android-теста настоящего обмена по HTTP с компьютером, без подмены Java API. Проверены нативный вход с неверным/верным кодом, запись, история, изменение числа мест, блокировка двойного нажатия и запрет запросов к продакшену. Локальный симулятор не подтверждает совместимость с реальным YCLIENTS.
