# Работа с проектом

- Для Jira, Confluence и Stash (Bitbucket) использовать MCP.
- Основное Android-приложение находится в `app/`, локальный имитатор API — в `local-server/`.
- В обычной сборке используется реальный YCLIENTS; `sandbox` обращается только к локальному серверу. Не переключать окружение автоматически при ошибках.
- Не создавать реальные SMS, бронирования или отмены при проверках. Инструментальные тесты выполнять на отдельном эмуляторе и изолированной базе локального сервера.
- Не сбрасывать базу пользовательского сервера. Для проверок запускать отдельный экземпляр на другом порту с отдельной базой и соответствующим `adb reverse`.
- Не коммитить ключи, `local.properties`, пользовательские базы, сеансы, файлы подписи или результаты сборки.
